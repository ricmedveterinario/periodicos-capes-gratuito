# Tipografia e legibilidade

Escala de leitura baseada no U.S. Web Design System (USWDS) e nas orientações
WCAG do W3C. WCAG não determina uma família tipográfica nem um tamanho mínimo
universal de fonte; os tamanhos abaixo são escolhas de projeto.

| Uso | Tamanho de referência com base de 16 px |
| --- | --- |
| Texto, campos, botões e abas | 16 px / 1 rem |
| Legendas, selos e fontes de dados | 14 px / 0,875 rem |
| Texto da barra lateral | 15 px / 0,9375 rem |
| Títulos de seção | 24–28 px / 1,5–1,75 rem |
| Título principal | 32–40 px / 2–2,5 rem |
| Valores das métricas | 30 px / 1,875 rem |

- Família: Arial, Helvetica, sans-serif, sem download de fontes externas.
- Entrelinha dos textos: 1,55; títulos: 1,2–1,35.
- Unidades rem e componentes flexíveis para respeitar o tamanho padrão e zoom.
- Contraste de texto normal com meta de pelo menos 4,5:1; gradiente do cabeçalho
  escurecido para o texto branco manter contraste.
- Rótulos permitem quebra de linha; números não são reduzidos a reticências.
- Alvos de botões com altura mínima de 44 px na base de referência.
- Anos das minilinhas e eixos dos gráficos ampliados, sem mudar os valores.

Aplicar estas escolhas não equivale a certificar conformidade WCAG. Ainda é
necessária validação visual com zoom de 200%, telas estreitas e tecnologias
assistivas para uma auditoria completa.
