# 💰 Publica Aberto - Sistema de Busca de Acordos CAPES

[![Streamlit](https://img.shields.io/badge/Streamlit-1.40.2-FF4B4B.svg)](https://streamlit.io)

**Website oficial:** [publicaberto.gobiota.com.br](https://publicaberto.gobiota.com.br)

## 📋 Sobre o Sistema

Sistema desenvolvido pelo **Grupo GOBIOTA (FMVZ/UFU)** para facilitar a busca de periódicos científicos e verificação de instituições elegíveis nos acordos transformativos entre CAPES e editoras internacionais, permitindo **publicação gratuita em acesso aberto**.

### 🎯 Principais Funcionalidades

- ✅ **Verificação de Instituição:** Consulta rápida para saber em quais editoras sua instituição é elegível
- ✅ **Busca de Periódicos:** Sistema avançado de busca por nome, ISSN ou editora
- ✅ **5.895 Periódicos:** Cobertura dos acordos CAPES com 8 editoras
- ✅ **2.483 Instituições:** Base de instituições brasileiras elegíveis
- ✅ **Interface Intuitiva:** Sistema em duas etapas (instituição → periódico)
- ✅ **Dados Atualizados:** Sincronização automática com fontes oficiais CAPES
- ✅ **Totalmente Gratuito:** Software livre e código aberto (MIT License)

### 💰 Impacto Financeiro

**Economize de US$ 1.500 a US$ 11.000** por artigo evitando custos de APC (Article Processing Charges).

## 🚀 Início Rápido

### Como Usar o Sistema

#### **PASSO 1: Verificar sua Instituição**
1. Acesse a seção "🏛️ PASSO 1"
2. Digite o nome ou sigla da sua instituição
3. Descubra em quais editoras você é elegível

#### **PASSO 2: Buscar seu Periódico**
1. Role até "📚 PASSO 2"
2. Digite o nome do periódico ou ISSN
3. Filtre pela editora onde você é elegível
4. ✅ Se encontrar → **Pode publicar GRÁTIS!**

### Critérios de Elegibilidade

✅ Você é o **autor correspondente** (corresponding author)  
✅ Sua **instituição** está nos acordos da editora  
✅ O **periódico** está listado nos acordos  
✅ Artigo submetido durante período de vigência
